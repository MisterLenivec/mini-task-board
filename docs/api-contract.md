# Контракт API и схема БД

Согласованный контракт API, реализованный и проверяемый в ветке dev.

## Таблица tasks

| Поле | SQLite | Ограничения |
| --- | --- | --- |
| id | INTEGER PRIMARY KEY | Назначается БД |
| title | TEXT NOT NULL | 1–200 символов после удаления пробелов по краям |
| description | TEXT NOT NULL | По умолчанию пустая строка, максимум 5000 символов |
| status | TEXT NOT NULL | todo / in_progress / done; по умолчанию todo |

Ограничения длины и допустимые статусы закрепляются CHECK в БД. API удаляет пробелы по краям title перед проверкой длины; пустое или состоящее из пробелов название недопустимо. Описание сохраняется обычным текстом. Символ U+0000 (NUL) запрещён в названии и описании: POST/PATCH возвращают 422, запрет также закреплён CHECK в SQLite. Названия не уникальны. Удаление окончательное. Временные метки, пользователи и порядок перетаскивания в схему MVP не входят.

## Маршруты

| Метод | Путь | Успех |
| --- | --- | --- |
| POST | /api/tasks | 201, объект задачи |
| GET | /api/tasks | 200, массив задач |
| GET | /api/tasks?status=todo | 200, массив выбранного статуса |
| GET | /api/tasks/{id} | 200, объект задачи |
| PATCH | /api/tasks/{id} | 200, обновлённый объект |
| DELETE | /api/tasks/{id} | 204, без тела |

JSON-объект ответа:

```json
{"id": 1, "title": "Создать первый тест", "description": "Проверить API", "status": "todo"}
```

POST: title обязателен, description по умолчанию `""`, status по умолчанию `"todo"`. id назначается сервером и не принимается во входном объекте.

PATCH принимает любое сочетание title, description, status. Пропущенные поля не меняются. `{}` — успешная операция без изменений. null недопустим во всех полях; описание очищается строкой `""`. Неизвестные поля отклоняются. Все переходы между тремя статусами разрешены; отдельного endpoint смены статуса нет.

GET без фильтра возвращает все задачи, с фильтром — один из трёх статусов. Сортировка id по возрастанию. Пустой результат — `[]`. Пагинации в MVP нет.

## Ошибки и документация

- Несуществующий id: 404, `{"detail": "Task not found"}`.
- Ошибки входных данных и неизвестный status фильтра: 422 в стандартном формате FastAPI.
- Документация OpenAPI через стандартный `/docs` после реализации.

## Критерии проверки

CRUD; значения по умолчанию; частичное обновление и пустой PATCH; очистка описания; все статусы и переходы; фильтр; пустая БД; одинаковые названия; отсутствующий id; null и неизвестные поля; неверный статус; границы длины и пустой title. Данные сохраняются при повторном открытии того же SQLite-файла. Ошибка валидации не изменяет сохранённую задачу.
